# Papaer Record

Paper Record 3.1 是一个**全文通读优先、证据链驱动、适合 Zotero/Obsidian 的论文研究知识库 Skill**。它面向需要真正读懂论文，而不是只要摘要的场景，尤其适合 AI/LLM × 计算机密码学近年论文的筛选、深读、比较和研究机会发现。

## 它解决什么问题

- 防止摘要级笔记冒充全文精读；
- 把“作者为什么这么做”写成可检查的因果链；
- 将图表、数据、公式、代码和参考文献连接到具体主张；
- 让 12 字段矩阵成为可靠索引，而不是空泛表格；
- 让主题地图能直接支持选题、实验和复现决策；
- 在交付前验证 Markdown、Obsidian、图片、PDF 和 HTML 链接是否真的可用。

## 最小使用方式

```text
使用 $papaer-record，针对 <主题>，按近五年范围建立新批次。
要求每篇论文全文通读，从零解释理论、作者思路、方法、实验、图表和结论边界，
先生成深度说理报告，再生成 12 字段证据矩阵，并完成材料使用、三种 renderer 和独立复核验收。
```

## 关键设计

1. 新批次使用 `layout_version: 3`；旧批次只读。
2. 每篇论文以 `02-深度说理报告.md` 为主产物，其他文件是证据和索引附件。
3. 所有结论必须能回链到全文页码/章节/图表/公式/附录。
4. 无法确认的信息必须写明检查范围和不确定性。
5. 六类门禁（结构、全文覆盖、报告逻辑、证据使用、实际渲染、独立复核）全部通过后才能交付。
6. 自动门禁通过不等于学术语义正确，必须保留独立复核；失败必须保持 `needs-optimization`。

统一验收命令：`python scripts/run_quality_gates.py --root <batch> --skill-root .`。详细规范见 `references/`，可执行模板见 `templates/`，验证工具见 `scripts/`；阶段变更和门禁结果记录在 `references/optimization-log-20260915.md`。
