# 分阶段验收门禁

## 1. 验收原则

验收是人工可判断的质量门，不是形式上的文件存在检查。每个阶段都必须同时提供数量统计、随机样例、失败清单和可复核路径。

阶段状态只允许：

```text
未开始 / 执行中 / 待验收 / 已通过 / 需优化 / 已停止
```

未获得用户明确确认时，不得从“待验收”进入下一阶段。

## 2. Stage 0：环境盘点验收

通过条件：

- [ ] Zotero当前库、集合和条目规模已记录；
- [ ] `AI文献库`是否存在已确认；
- [ ] Obsidian Vault路径已确认；
- [ ] 当前工作目录和输出目录已确认；
- [ ] 原始文件、旧版本和备份策略已确认；
- [ ] 用户主题、时间范围、语言和排除标准明确。

暂停条件：连接未知、目标范围模糊、输出位置未知、会覆盖现有文件。

## 3. Stage 1：检索与导入验收

> 空白分类索引或初始化模板不算导入记录；必须至少存在一条真实论文记录或明确的失败/待复核记录。

建议指标：

- 论文总数、去重后数量、按分类数量；
- DOI/原文链接完整率；
- PDF已挂接率；
- 重复候选数；
- 待分类数；
- 元数据缺失数。

通过条件：

- [ ] 所有条目来源可解释；
- [ ] 分类规则可复核；
- [ ] Zotero集合与清单一致；
- [ ] 没有明显重复或错误条目；
- [ ] 每条至少有DOI或原文链接，缺失项进入复核表。

## 4. Stage 2：PDF/SI验收

通过条件：

- [ ] 每个已挂接PDF的题名/作者/DOI与条目一致；
- [ ] SI没有被误挂为正文PDF；
- [ ] 下载失败项目有原文链接和失败原因；
- [ ] 失败CSV可打开，字段齐全；
- [ ] 原始文件未被覆盖。

暂停条件：出现任何错配、同名文件无法判定、下载来源无法记录。

## 5. Stage 3：手动文件验收

通过条件：

- [ ] 自动挂接的文件均有唯一匹配依据；
- [ ] 未匹配和多候选文件均列出；
- [ ] Zotero附件与本地文件可定位；
- [ ] 重复文件可区分；
- [ ] 用户原始目录未被移动或删除，除非用户明确要求。

## 6. Stage 4：APA与矩阵验收

通过条件：

- [ ] 每篇论文一行；
- [ ] 每个分类有独立Sheet；
- [ ] APA字段不包含编造的卷期、页码、DOI或作者；
- [ ] 分类和总览数量一致；
- [ ] Zotero Item ID、笔记链接和图表链接可追踪；
- [ ] Excel可打开且中文不乱码。

## 7. Stage 5：标签验收

通过条件：

- [ ] 原标签完整保留；
- [ ] 新标签遵循命名空间；
- [ ] 标签值确有论文依据；
- [ ] 标签不承载长篇结论；
- [ ] 分类、标签、矩阵主题没有明显冲突。

## 8. Stage 6：参考文献验收

通过条件：

- [ ] 每条参考文献能追溯至来源论文和原始编号；
- [ ] 去重不会丢失来源关系；
- [ ] `references.bib`语法可导入；
- [ ] Excel包含master和occurrence关系；
- [ ] 冲突、未核验和无法解析项显式列出。

## 9. Stage 7：深读、图表和知识网络验收

通过条件：

- [ ] 14个字段表头严格一致；
- [ ] 原文未提供的字段正确标记；
- [ ] 研究问题、方法、数据、图表、结果和结论形成证据链；
- [ ] 每张关键图表都有编号、标题、章节/页码和独立卡片；
- [ ] 图像只含图表本体，不含整页截图或无关正文；
- [ ] 图表已放在论文笔记对应章节附近；
- [ ] 解析区分数据观察、作者主张和个人推论；
- [ ] 明确结论外推边界；
- [ ] 跨论文关系有理由和证据；
- [ ] wikilink、图片相对路径和Dataview字段可用。

## 10. 低质量处理方式

如果用户指出质量不够：

1. 将阶段状态改为`需优化`；
2. 记录用户反馈原文和受影响文件；
3. 不推进后续阶段；
4. 先给出优化范围和预期变化；
5. 用户确认后只重做指定部分；
6. 用新批次或版本目录保存优化结果；
7. 再次生成同一阶段验收报告。

常见反馈到修复动作：

| 用户反馈 | 修复动作 |
|---|---|
| 图表不清楚 | 重新定位、裁剪、核对图号和图注，不使用整页截图 |
| 不能回到原文 | 增加章节、页码、段落或PDF页内锚点 |
| 看不出论文逻辑 | 重写“研究缺口→问题→方法→证据→结论”论证链 |
| 笔记太长难检索 | 主笔记导航化，细节拆成子笔记或证据卡 |
| 分类混乱 | 输出分类规则、候选分类和人工复核清单 |
| 结论像是猜的 | 分离原文摘录、结构化转述和个人推论，降低证据等级 |
| Obsidian打不开链接 | 修复相对路径、wikilink文件名和URI，并重新验证 |
