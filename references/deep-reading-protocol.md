# 逐篇全文深读协议（Paper Record 3.0）

## 最小阅读单位

```text
一篇论文 + 核验版本的全文 + 图表/公式/数据/代码/参考文献材料
+ 全文覆盖轨迹 + 一份深度说理报告 + 证据册 + 12字段矩阵
```

## 逐篇产物

```text
03-逐篇精读/P001--YYYY--short-slug/
├── 00-论文入口.md
├── 01-全文通读轨迹.md
├── 02-深度说理报告.md
├── 03-12字段证据矩阵.md
├── 04-图表公式证据册.md
├── 05-实验数据与复现.md
├── 06-参考文献脉络.md
└── 07-主张证据与边界.md
```

## 阅读顺序

1. **结构通读**：确认研究类型、章节功能、问题定义、方法、实验/证明、结论和局限位置。
2. **理论通读**：对每个核心概念写“是什么—本文如何用—假设—不成立后果”。
3. **作者思路通读**：重建观察→瓶颈→假设→表示→设计选择→预期机制。
4. **方法与实验通读**：核对输入、状态、输出、失败分支、数据、基线、预算、指标和成功判据。
5. **材料通读**：逐项核对图表、公式、附录、补充材料、代码和关键参考文献。
6. **整合通读**：整合者重新打开PDF和全文，先写主报告，再回填证据册和矩阵。

## 图表/公式最低记录

每项记录原始定位、图注/公式含义、变量、条件、直接观察、正文关系、支持Claim、进入字段、不能推出项和素材路径。流程图不等于性能结果；无误差条不能自行声称显著；缩减轮攻击不能写成全轮破解。

## 结果最低记录

每个结果必须回答：结果是什么、在什么条件下、和谁比较、回答哪个问题、支持哪条结论、不能外推到哪里。理论论文把“实验”替换为定义、定理、证明义务、假设和反例。

## 结论分层

- `[原文证据]`：明确定位的事实或短引；
- `[结构化转述]`：忠实解释，不扩展因果；
- `[本次综合推论]`：由多条直接证据推导，说明推理跨度。

任何OCR失败、未获得SI、代码不可得或页码对不齐，都要写入通读轨迹和阻塞原因。
