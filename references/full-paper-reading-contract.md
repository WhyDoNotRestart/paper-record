# 全文通读合同

## 1. 什么叫“通读完成”

通读不是读摘要，也不是把PDF转成文本。至少要覆盖并记录：

- 标题、摘要、关键词和引言；
- 相关工作中与问题定义、基线和差异直接相关的部分；
- 理论、威胁模型、密码学假设或机器学习设定；
- 方法、算法、协议、伪代码、公式和实现细节；
- 数据、实验、基线、指标、消融、失败样例和附录；
- 全部图表标题/图注，至少逐项核对核心数据；
- 讨论、结论、局限、未来工作和参考文献中关键引用；
- 补充材料、代码仓库和数据集（已获得或明确未获得）。

如OCR、扫描页、公式或附录无法读取，必须写入阻塞原因和影响，不能标记完成。

## 2. 通读轨迹必须记录什么

```yaml
paper_id: P001
source_pdf: ../04-证据仓/.../source/P001.pdf
fulltext_version: v1
page_count: 18
coverage:
  - range: "p1-p3"
    sections: "abstract/introduction"
    status: read
    evidence_ids: [E-P001-001]
  - range: "p4-p8"
    sections: "method"
    status: read
    evidence_ids: [E-P001-002]
figures_checked: [FIG-01, FIG-02]
tables_checked: [TAB-01]
appendix_checked: true
references_roles_checked: [R-03, R-07]
open_questions: []
```

## 3. 阅读顺序

### 第一遍：结构和问题

回答论文属于哪类研究、研究对象是什么、问题在哪里定义、方法和实验如何组织、结论在哪里收束。

### 第二遍：理论和设计

对每个核心概念写出“是什么—本文如何使用—假设是什么—假设不成立会怎样”，并重建“观察→瓶颈→假设→设计选择”。

### 第三遍：方法、实验和证据

逐项核对输入、状态、输出、预算、数据、基线、变量、指标、成功判据、失败样例、图表和附录。

### 第四遍：整合和边界

从零写主报告，区分作者明确主张、结构化转述和本次综合推论；再回填矩阵和跨论文材料。

## 4. 不同论文类型的适配

- 理论/证明：将“实验”替换为定义、定理、证明义务、假设和反例检查；
- 实证/基准：强调样本、划分、污染、指标、统计不确定性和基线；
- 系统/工程：强调威胁模型、接口、资源预算、故障模式和部署条件；
- 攻击/密码分析：明确攻击目标、轮数/范围、密钥信息、成功率和复杂度，禁止扩大攻击结论；
- 综述：明确检索策略、纳入标准、分类框架和证据覆盖，不把综述观点写成新实验结论。

## 5. 完成签收

通读任务只有在覆盖记录、主报告、证据册、矩阵、阻塞说明和独立复核栏都存在后才能进入 `completed`。整合负责人必须重新通读全文，不能把多个阅读者的片段直接拼接。
