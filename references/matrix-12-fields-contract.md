# 12字段证据矩阵合同

矩阵用于横向检索和比较，不替代主报告。每个字段必须同时回答：**结论是什么、为什么这样判断、全文哪里支持、适用条件和不确定性是什么、关联哪些Evidence/Material。**

| ID | 字段 | 必须回答的问题 |
|---|---|---|
| F01 | 研究类型 | 是理论分析、实证、综述、案例、实验、方法改进、系统实现、基准、攻击还是组合类型？全文判断依据是什么？ |
| F02 | 研究问题 | 用1–2句话写出核心问题；成功解决的判据是什么？ |
| F03 | 研究主题 | 属于哪条具体主线和细分方向？与相邻方向如何区分？ |
| F04 | 研究目的与核心问题 | 为什么做（目的）与要回答什么（问题）分别是什么？ |
| F05 | 研究对象与应用场景 | 对象、样本/协议/模型/算法、行业领域和实际场景是什么？ |
| F06 | 研究方法/技术路径 | 方法论、模型、算法、实验设计或分析框架如何按步骤运行？ |
| F07 | 数据与材料来源 | 数据/论文/PDF/SI/代码来源、规模、时间、划分、采集方式、许可和缺失项是什么？ |
| F08 | 主要发现/关键结果 | 最重要的结果是什么？保留条件、基线、指标、范围和异常，不只写数字。 |
| F09 | 创新点/贡献 | 理论、方法、实践贡献分别是什么？与已有工作相比新增了什么？证据是否直接？ |
| F10 | 结论摘录 | 从结论/讨论中摘录短句或忠实转述，保留定位；哪些是作者说的，哪些是整理者说的？ |
| F11 | 实际意义/应用价值 | 能服务什么实践、产业、政策或后续研究？在什么条件下适用？ |
| F12 | 关键词标签 | 3–8个可检索标签，包含主题、原语/模型、方法或指标，避免泛词。 |

## 字段格式

```markdown
## F06 研究方法/技术路径

### 字段结论
[结构化转述] ...

### 判断依据
[原文证据] 方法章节说明 ...

### 全文锚点
- PDF p.5, Sec. 3.1, Eq. (2), Figure 2

### 适用条件与边界
- 只在 ... 条件下成立；论文未报告 ...（已检查 p.9–p.12 与 Appendix）。

### Evidence / Material
- Evidence: E-P001-004, E-P001-FIG-02
- Material: MAT-P001-PDF, MAT-P001-FIG-02
```

## 判定等级

- `direct`：正文、图表、公式、附录或结论直接支持；
- `partial`：只能支持字段的一部分；
- `inference`：整理者基于多条证据的推论；
- `unverified`：材料不可得、冲突或无法核验。

不要用字符数冒充丰富度。若论文没有报告，写明检查范围；若字段不适用，说明为什么不适用。
