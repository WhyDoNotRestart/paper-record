# 链接与渲染兼容规范

## 目标

同一批次要能在普通Markdown、Obsidian和独立HTML预览中打开。文件存在不等于可展示，必须以源文件所在目录解析相对路径并实测。

## 推荐写法

```markdown
![FIG-01 方法流程](../../04-证据仓/P001--2024--paper/figures/P001--FIG-01--method.png)
[打开图表证据卡](../../04-证据仓/P001--2024--paper/figures/P001--FIG-01--evidence.md)
[打开原始PDF](../../04-证据仓/P001--2024--paper/source/P001--2024--paper.pdf)
[[03-逐篇精读/P001--2024--paper/02-深度说理报告]]
```

## 禁止

链接目录、盘符/机器绝对路径、只写YAML路径、图片只嵌证据卡不嵌图片、依赖错误工作目录的HTML相对路径、未验证就生成Zotero URI。

## 验收记录

链接审计必须记录源文件、语法、目标、解析后的相对路径、目标类型、是否存在、是否为目录、渲染器和状态。图片至少抽取一套HTML预览，并记录图片加载结果。
