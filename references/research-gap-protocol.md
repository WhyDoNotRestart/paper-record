# 研究机会与科研资产协议（Paper Record 3.1）

## 研究机会不是愿望句

研究机会必须由逐篇证据和主题差异推导，不能只写“值得进一步研究”“可以提升性能”或“未来可扩展”。

## 研究机会卡必填字段

```text
机会 ID
来源论文与 Evidence/Claim
作者明确局限 / 本次综合推论
现有研究已经解决什么
尚未解决的可观察缺口
可检验研究问题
假设与预期机制
数据/协议/模型/样本
自变量
因变量
控制变量
基线与对照
指标
成功判据
统计或证明方案
威胁、风险、许可和复现障碍
预期理论/方法/实践贡献
失败后仍能得到什么信息
```

## 从主题差异到研究机会

```text
论文结果差异
→ 检查是否可比
→ 排除数据/预算/威胁模型差异
→ 定位可观察缺口
→ 提出可证伪假设
→ 设计变量、基线和指标
→ 定义成功与失败判据
```

没有完成可比性检查的差异不能直接写成研究空白。

## 科研资产卡

每个资产必须写来源、输入、输出、变量、参数、环境、执行步骤、适用条件、不可外推场景、许可、复现状态和真实消费者。资产只有在未来研究能够直接拿来使用时才进入 `08-复现与科研资产`。

## 禁止

- 只写“值得进一步研究”；
- 把作者未提出的推论伪装成作者结论；
- 把不同威胁模型、数据或预算下的结果直接合并；
- 没有 Evidence/Claim 就生成研究机会；
- 没有变量、基线、指标和成功判据就标记为可执行机会。
