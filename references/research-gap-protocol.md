# 研究机会与科研资产协议

## 研究机会卡

每个机会必须是可执行的研究设计，而不是愿望句。至少包含：

```text
来源论文与Evidence
作者明确局限 / 综合推论
现有研究已经解决什么
尚未解决的可观察缺口
可检验研究问题
假设与预期机制
数据/协议/模型/样本
自变量、因变量、控制变量
基线与对照
指标、成功判据和统计方案
威胁、风险、伦理/许可或复现障碍
预期理论/方法/实践贡献
```

## 科研资产卡

每个资产要写来源、输入、输出、变量、参数、环境、执行步骤、适用条件、不可外推场景、许可和复现状态。资产只有在未来研究可直接拿来使用时才进入 `08-复现与科研资产`。

禁止：只写“值得进一步研究”；把作者未提出的推论伪装成作者结论；把不同威胁模型下的结果直接合并。
