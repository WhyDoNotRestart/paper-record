# 语义质量门禁

## 必须形成的论证链

```text
问题背景 → 具体瓶颈 → 研究问题 → 理论/假设
→ 作者观察 → 设计选择 → 方法执行 → 实验/证明
→ 图表证据 → 结果 → 结论 → 局限/外推边界
```

## 每篇论文最低要求

- 通读轨迹覆盖全文主要部分，并列出未获得材料；
- 主报告不是摘要改写，至少有4个论文特异性事实和3个直接证据锚点；
- 理论概念至少写“是什么—本文如何用—不成立后果”；
- 方法写输入、处理、中间状态、输出和失败分支；
- 实验写变量、样本/模型、基线、预算、指标、成功判据和异常；
- 图表逐项说明变量、条件、观察、支持Claim和不能推出项；
- 12字段逐项有依据、锚点、边界和Evidence/Material ID；
- 参考文献、数据、代码和补充材料有实际使用状态；
- 作者主张、结构化转述和本次推论不混写。

## 反空洞规则

触发失败：只有工具名、只有“效果较好”、只有结果数字没有条件、只有路径没有用途、把语法通过写成安全证明、把缩减轮写成全轮、把密钥差值写成完整密钥、把准确率写成协议安全性、跨论文复制同段落。

字符数只是报警信号，不是通过条件。自动门禁不能证明密码学语义正确。
