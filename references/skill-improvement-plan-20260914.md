# Paper Record Skill 完善计划（2026-09-14）

## 目标

把“文件齐全但内容空洞、路径存在但不可展示、主题目录像入门教程、图表和参考文献只归档不参与论证”的问题，改造成一套可执行、可审计、可回滚的全文研究工作流。本计划只约束未来新批次，不要求修改任何既有论文产物。

## 缺陷—改造对照

| 已知缺陷 | 根因 | Skill层修复 | 验收方式 |
|---|---|---|---|
| 每篇文件短、互相重复 | 把章节数量误当作理解深度 | 以一份主报告串联完整论证链，附件只承载证据 | 主报告合同 + 论文特异性检查 |
| 12字段干瘪 | 只有字段名，没有判断依据和边界 | 每字段固定“结论—依据—锚点—边界—证据ID” | `check_matrix_field_richness.py` |
| 02/03无研究决策价值 | 主题按入门等级组织 | 改为问题树、方法谱系、可比性、失败模式、可检验机会 | 主题综合合同 |
| 图表/路径不能展示 | 仅检查文件存在 | 统一相对路径、图片+证据卡双入口、真实渲染预览 | `check_links.py` + `render_markdown_preview.py` |
| 参考文献只列清单 | 没有引用角色和论证用途 | occurrence级角色台账与关键引用脉络 | 材料使用合同 |
| 通读任务流于形式 | 任务与实际产物不同步 | 下载后立即创建任务，要求覆盖记录、整合者、独立复核 | `check_reading_task_completion.py` |
| 初始化与验证目录矛盾 | 存在两套历史布局 | 版本化 layout，统一公共路径解析器，兼容旧批次只读审计 | `validate_paper_record.py` |
| 只靠字符数/绿色CI | 自动门禁没有语义边界 | 自动检查明确“只能检查合同”，完成状态需人工签收 | `acceptance-gates.md` |

## 实施阶段

1. **冻结基线**：保存当前Skill快照，明确旧批次不改。
2. **重构入口**：压缩 `SKILL.md`，把细节下沉至 references。
3. **重构未来目录**：启用 layout v3 和短命名，减少碎片文件。
4. **补齐生产合同**：全文通读、主报告、12字段、材料使用、主题和研究机会。
5. **补齐模板**：任务、主报告、矩阵、图表证据卡和材料台账。
6. **统一工具链**：公共路径解析、初始化、验证、总门禁、渲染和Skill自检。
7. **隔离烟雾测试**：在临时目录生成最小批次，只验证Skill行为，不接触既有产物。
8. **独立复核与回炉**：自动门禁通过后，抽查证据链和结论边界；失败则回到对应阶段。

## 完成标准

- 新批次默认生成 layout v3；
- 每篇论文都有一份主报告和全文覆盖记录；
- 12字段逐项可追溯；
- 图表、数据、参考文献和代码有实际使用状态；
- 主题图谱能输出论文关系、证据差异、失败模式和可检验问题；
- 所有入口链接到实际文件并通过渲染烟雾测试；
- 初始化脚本、验证器和模板字段一致；
- 旧批次没有被修改；
- `completed` 只在四类门禁和独立复核均通过后写入。

## 不在本轮范围

- 不批量重写既有论文笔记；
- 不自动下载或替换用户的论文；
- 不擅自修改Zotero；
- 不把某个具体论文批次的内容硬编码为通用规则。
