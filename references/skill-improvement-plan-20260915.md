# Paper Record 3.1 优化计划（2026-09-15）

## 目标

把 Paper Record 从“文件齐全的论文归档”升级为“可展示、可追踪、可解释、可支持研究决策的证据型论文知识库”。本版本采用 Git 分支逐阶段优化；旧批次只读，需要修复时生成新 revision。

## 鲁班执行纪律

- 分支：`codex/luban-paper-record-3.1`；不修改 `main`，不 merge、tag、release。
- 每轮只优化一个主要问题面；每轮独立提交并推送。
- 每处理一个文件，立即登记 `FILE_CLASSIFICATION.md`。
- 每阶段结束发送精简报告，并在 `references/optimization-log-20260915.md` 留档。
- 失败状态保留为 `needs-optimization`，不能用增字、复制模板或放宽阈值掩盖失败。
- `completed` 需要结构、全文语义、证据使用、实际渲染和独立复核全部通过。

## 阶段

1. **验料、基线与访行**：冻结基线，建立隔离 fixture，复现无效媒体、路径存在但不可展示、材料登记但未进入论证等失败；记录至少五类同类工具/工作流的可核验来源。
2. **渲染与路径**：统一链接解析；校验图片/PDF真实性；对 Markdown、Obsidian、独立 HTML 实际渲染验收。
3. **逐篇深度报告**：强制形成“背景→瓶颈→问题→理论/假设→观察→设计→方法→实验/证明→图表证据→结论→边界”的主叙事。
4. **材料闭环**：实现 `Material→Evidence→Claim→Matrix Field→Report/Topic/Opportunity` 双向追踪；参考文献采用 occurrence 级角色台账。
5. **主题与跨论文比较**：禁止入门/进阶/高级路线；改为问题树、机制谱系、可比性、证据差异、失败模式和可检验机会。
6. **总验收与回炉**：真实小批次回放、独立复核、最终门禁、README/日志/分类清单更新。

## 完成标准

- 核心图表和 PDF 在 Markdown、Obsidian、HTML 中实际可展示；
- 每篇论文有全文覆盖、深度说理报告、证据册、复现说明和边界说明；
- 每个核心材料都有真实用途或明确未使用原因；
- 主题目录直接支持论文比较、失败定位和研究设计；
- 自动门禁不再把字符数、文件数或路径存在当作深度证明；
- 独立复核完成后才允许标记 `completed`。
