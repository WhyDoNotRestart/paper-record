# 主题研究图谱协议（Paper Record 3.1）

主题图谱面向研究决策，不是入门教程。它只能由已经通过逐篇全文语义、证据使用和渲染门禁的论文材料生成。

## 主题包结构

```text
05-主题研究图谱/T01--short-topic-slug/
├── 00-主题入口.md
├── 01-问题树.md
├── 02-理论与方法谱系.md
├── 03-论文关系与可比性.md
├── 04-证据差异与结果对照.md
├── 05-失败模式与边界.md
└── 06-可检验研究机会.md
```

## 禁止的组织方式

禁止使用以下结构作为主题主线：

```text
入门 → 进阶 → 高级
基础知识 → 常用方法 → 前沿方向
```

主题入口可以提供极短的先修说明，但不能让概念教程替代论文关系、证据差异和研究机会。

## 各文件必须回答

### 00-主题入口

- 主题对象、边界和不纳入范围；
- 纳入哪些已通过门禁的论文；
- 主题的总研究问题；
- 该主题包能够支持哪些比较、选题、实验或复现决策。

### 01-问题树

每个问题节点必须包含：父问题、子问题、相关论文、Evidence/Claim、当前解决状态、未解决部分和证据强度。

### 02-理论与方法谱系

按机制而不是难度排序。每种机制记录关键假设、输入、处理机制、输出、成功条件、失败模式、代表论文和 Evidence/Claim。

### 03-论文关系与可比性

每条关系记录来源论文、目标论文、关系类型、可比维度、不可比条件和证据定位。关系类型包括基准、改进、补充、对比、冲突和相邻。

### 04-证据差异与结果对照

不能只抄结果数字。必须同时记录任务/数据、模型/协议、变量、基线、预算、指标、成功判据、异常、证据来源和可信范围。

### 05-失败模式与边界

集中记录作者明确失败、负结果、复现失败、材料缺失、威胁模型外场景、不可比结果和不能从论文推出的结论。

### 06-可检验研究机会

每个机会必须能够转成研究设计，包含来源 Evidence、可观察缺口、可检验研究问题、假设、数据/模型、自变量、因变量、控制变量、基线、指标、成功判据、风险和预期贡献。

## 证据规则

- 每个主题判断至少链接一个论文 ID 和一个 Evidence/Claim；
- 综合推论必须由至少两篇论文或两条直接 Evidence 支持；
- 不可比性必须写明原因，不能为了生成统一表格而强行比较；
- `context-only` 或 `unavailable` 材料不得伪装成直接结果证据；
- 主题机会必须回链到逐篇报告，不允许凭主题模板独立生成。

## 验收

主题包必须通过：结构完整、非教程化、论文关系、可比性、证据差异、失败边界和研究机会七项检查。任何文件只有标题或概念介绍时，主题状态保持 `needs-optimization`。
