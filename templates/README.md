# Paper Record 3.0 模板使用说明

模板是起点，不是填空答案。先用全文材料填写证据和定位，再写中文解释；没有报告的信息必须写检查范围和受控状态。

| 模板 | 生成位置 | 用途 |
|---|---|---|
| `reading-task.md` | `09-质量审计/reading-tasks/` | 下载后立即创建通读任务 |
| `paper-report.md` | `03-逐篇精读/<paper>/02-深度说理报告.md` | 每篇论文唯一主叙事 |
| `matrix-12-fields.md` | `03-逐篇精读/<paper>/03-12字段证据矩阵.md` | 逐字段证据索引 |
| `figure-evidence-card.md` | `04-证据仓/<paper>/figures/` | 图表/表格/公式证据卡 |
| `material-usage-ledger.csv` | `09-质量审计/` | 材料实际用途审计 |

禁止把模板中的占位符原样交付；自动门禁只检查合同，不能代替全文理解。
